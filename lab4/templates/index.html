Оценка качества перевода

Каждый текст переводится двумя методами — системой с трансфером и прямым пословным переводом — и сравнивается с эталонным переводом: BLEU (совпадение n-грамм слов, n = 1…4) и chrF (совпадение символьных n-грамм). На отладочной выборке разрабатывались правила, поэтому её оценки завышены; честная оценка — тестовая выборка.

Перевод

  • Вставьте английский текст, выберите пример или откройте файл TXT, DOCX, PDF (можно перетащить в поле).
  • Система с трансфером выполняет анализ (разбор spaCy), перенос структуры по правилам французского языка и синтез форм. Прямой перевод заменяет слова и обороты по словарю в исходном порядке — для сравнения.
  • Предметная область определяется по словам текста; от неё зависит выбор значения (language → langage / langue).
  • Под переводом — число слов во входном тексте, число переведённых и не найденных в словаре слов.
  • «Сохранить … (TXT)» — файл в кодировке Unicode (UTF-8 с меткой BOM или UTF-16); «Печать» — печать текущей вкладки.

Вкладка 1 · Слова по частоте

  • Все слова текста (по леммам) упорядочены по частоте.
  • Для каждого слова: формы в тексте, часть речи и тег Penn Treebank с расшифровкой, роль в предложении, морфологические признаки (функциональность ЛР №3 весеннего семестра).
  • Перевод из словаря и грамматическая информация о французском слове: род, мн. число, формы прилагательного, спряжение глагола.

Вкладка 2 · Дерево разбора

  • Выберите предложение (или щёлкните его в таблице на вкладке «Перевод»).
  • Зависимости: вершина — слово с тегом и переводом, подпись дуги — синтаксическое отношение.
  • Составляющие: группы S, NP, VP, PP, ADJP, построенные из дерева зависимостей.
  • Наведите на узел, чтобы увидеть расшифровку тега.

Словарь

  • Словарь хранится в PostgreSQL: английская лемма, часть речи, перевод, род, дополнительные формы, область.
  • Пополнение: неизвестные слова всех переводов собираются автоматически, для них предлагается перевод; исправьте его при необходимости и добавьте отмеченные строки.
  • Поле «доп.»: pl= мн. число, f= ж. род прилагательного, pre — прилагательное перед существительным, aux=être, obj=à — дополнение-лицо с предлогом, inf=de — предлог перед инфинитивом.
  • Записи можно править и удалять, выгружать и загружать в формате TSV.

Оценка качества

  • BLEU — доля совпадающих последовательностей из 1–4 слов с эталонным переводом (со штрафом за краткость).
  • chrF — F-мера по последовательностям символов, менее строга к ошибкам в окончаниях.
  • Покрытие — доля слов, для которых найден перевод.

Ограничения

  • Перевод строится по правилам и словарю; идиомы, которых нет среди оборотов, переводятся дословно.
  • Ошибки анализатора spaCy (неверная часть речи или связь) переходят в перевод.
  • Местоимения it / they согласуются с ближайшим подходящим существительным; это не всегда верно.
